# FIFO ○×ゲームのルール

[← README に戻る](../README.ja.md)

## 盤と手番

マスには左上から 1〜9 の番号を振る．

```text
1 | 2 | 3
--+---+--
4 | 5 | 6
--+---+--
7 | 8 | 9
```

`--first o` を付けない限り `X` が先手である．一列は横 3 本・縦 3 本・斜め 2 本の 8 本で，自分の手で一列をそろえた側が勝つ．

## 上限と手の消去

プレイヤー `i` は盤に残せる手の数に上限 `k_i` を持つ．すでに `k_i` 個の手が盤にあるときに打つと，自分の手のうち **最も古いもの** が消える．各プレイヤーの手は先入れ先出し (FIFO) のキューのように振る舞う．上限が `inf` の側は手が消えない．`k_X = k_O = inf` なら古典的な○×ゲームになる．

`k_X, k_O ∈ {1, 2, 3, 4, inf}` のすべての組，つまり 1 規則あたり 25 条件を解く．

## 消えるタイミングの 3 規則

最も古い手がいつ消えるかでゲームが変わるので，3 つの規則を解く．

| 規則 | 1 手の中の順序 | 効き方 |
|---|---|---|
| `t1` | 最古の手を消す → 打つ → 一列を判定 | 消えたばかりのマスに打てる |
| `t2` | 打つ → 一列を判定 → 最古の手を消す | 消える直前の手も一列に数える |
| `t3` | 打つ → 最古の手を消す → 一列を判定 | 盤に残った手だけを数える |

主の規則は `t3` で，`t1` と `t2` は比較のために解く．

`t1` と `t3` では，上限が 2 以下の側は一列を作れない．`t2` では判定のときに `k_i + 1` 個の手が盤にあるので，一列を作れないのは上限が 1 の側だけである．

## 対局の終わり

- **一列．** 打った側が一列をそろえた時点で終わり，打った側の勝ちとする．変わるのは打った側の手だけなので，一列を作れるのは打った側だけである．
- **打てる手が無い．** 手番の側に打てる空きマスが無ければ引き分けとする．`t1` では上限に達した側は先に手を消すので，盤が埋まって見えても必ず打てるマスがある．
- **終わらない対局．** 手が消えるので同じ局面が繰り返されうり，対局が終わらないことがある．どちらも勝ちを強制できない対局は **引き分け** とする．このために手数の上限は置かない．後退解析で最後まで値が決まらなかった局面を引き分けとする ([解き方](method.ja.md) を参照)．

したがって局面は盤面だけではなく，盤面・各プレイヤーの手の **古い順**・手番の組である．盤面が同じでも，最も古い手が違えば結果が違いうる．

## 感度分析の変種

- **手数の上限 `H`．** `solve --horizon H` は «終わらない対局は引き分け» の代わりに «`H` 手以内に決着しなければ引き分け» とする．実験では `H = 20, 50, 100` を使う．
- **後手から始める．** `solve --first o` は `O` を先手にする．値は引き続き `X` から見て書く．
