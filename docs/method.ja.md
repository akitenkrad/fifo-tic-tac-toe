# 解き方と検査

[← README に戻る](../README.ja.md)

## 局面

局面は `(q_X, q_O, p)` である．各プレイヤーの手を古い順に並べた列と，手番からなる．上限が `inf` の側は手が消えないので，手を順序の無い集合として持つ．局面全体は `u64` 1 つに詰める．

## 列挙

空の盤・`X` の手番から始めて，到達できる局面を幅優先ですべて列挙し，前向きの辺 (着手) と逆向きの辺を持つ．打った側が一列をそろえる辺は «勝ちの辺» として持つ．`t2` では判定の後に最古の手が消えるので，そろった一列が次の局面に残らないことがある．そのため勝ちは，行き先の盤面からではなく辺に持たせる．

局面数には空の盤と終端の盤を含む．古典的な○×ゲーム (`k_X = k_O = inf`) では，よく知られた 5,478 局面になる．

## 後退解析

各局面に «相手の勝ちと確定していない後続の数» のカウンタを持つ．

1. 勝ちの辺を持つ局面は，手番の側の勝ち．
2. ある局面が **負け** になったら，その前任の局面はすべて **勝ち** になる．
3. ある局面が **勝ち** になったら，前任の局面のカウンタを 1 減らす．カウンタが 0 になった前任は **負け** になる．
4. 局面は幅優先 (FIFO) の順に処理するので，最初に付いた手数が最善の手数になる．勝つ側はできるだけ早く勝ち，負ける側はできるだけ長く粘る．
5. 最後まで値が付かなかった局面は **引き分け** である．手数の上限を置かずに終わらない対局を評価するのはこの仕組みである．

主な結果は，`X` から見た初期局面の値と決着までの手数である．盤の対称性でまとめた初期局面の最善手も出す．

## 手数の上限

`--horizon H` では，局面に残り手数を加えたうえで後ろ向き帰納法で解く．残り手数 0 で決着していなければ引き分けとする．これは値反復を `H` 回で止めたものと同じ漸化式である．`H` 手以内に勝ちを強制できる局面の集合は `H` について増える一方なので，値は上限なしの値へ単調に近づき，`H` の偶奇で揺れない．

## 素朴な探索

`naive` は同じ条件を素朴なネガマックスで解く．メモ化も枝刈りもせず，探索中の経路に同じ局面がすでにあれば，その子を引き分けとして打ち切る．訪問ノード数は根と，生成したすべての子 (終端の子と，繰り返しで打ち切った子を含む) の数である．古典的な○×ゲームではゲームの木全体の 549,946 ノードになる．探索は明示的なスタックで行い，`--node-cap` ノード (既定 10^9) で止める．上限に達した条件は打ち切りとして記録し，そのノード数と値は出さない．

## 検査

どの run も検査の結果を `check.{id}` (1 = 通過，0 = 失敗) と `checks_failed` に記録する．検査が 1 つでも失敗すると run は `failed` で閉じる．検査を飛ばすオプションは無い．

| ID | 検査 |
|---|---|
| `v1` | 古典的な○×ゲーム (`inf`, `inf`) で，3 規則とも 5,478 局面 (対称性でまとめて 765)・255,168 対局になる |
| `v2` | 古典的な○×ゲームは引き分け |
| `v3` | 一列を作れない上限 (`t1`/`t3` で 2 以下，`t2` で 1) では全局面が引き分け．`t2` では上限 2 で一列ができうる |
| `v4` | D4 で正準化した局面のグラフを解くと，すべての局面で値と手数がその代表の局面と一致する |
| `v5` | 遷移規則と局面の一覧だけを共有する独立な値反復で，全局面の値と手数が一致する |
| `v6` | 局所の整合: 手数 `n` の勝ちには手数 `n − 1` の負けへ動く手があり，手数 `n` の負けからの手はすべて手数 `n − 1` 以下の勝ちへ行く |
| `v7` | 両者が最善手を選ぶ対局を socsim で回すと，解いた手数ちょうどで解いた結果になる．引き分けの対局は局面の繰り返しか引き分けの終端で終わり，安全のための打ち切りには達しない |
| `v8` | 手数の上限 `H` のもとで，全局面が «上限なしの手数が残り手数以下なら上限なしの値，そうでなければ引き分け» に一致する |
| `v9` | `O` 先手・上限 `(k_X, k_O)` の値は，`X` 先手・上限 `(k_O, k_X)` の値の符号を反転したもので，手数も等しい |
| `v10` | 素朴な探索が上限内で終わった条件では，初期局面の値が後退解析と一致する．古典的な○×ゲームではちょうど 549,946 ノードになる |
| `v11` | 最善手の側は一様ランダムの相手に対して解いた値を下回らず，勝ちの条件では解いた手数以内に勝つ |
| `r41` | 終端でない局面に一列は無く，勝ちの辺はどれも打った側の一列だけを完成させる |

`v1`・`v2`・`v10` のアンカーは [`reference.csv`](../reference.csv) に置いている．
